# Rokid Camera Link

Samostatná testovacia aplikácia pre Rokid/YodaOS.

Po spustení aplikácia otvorí kameru cez Android Camera2 API a zobrazí IP adresu, napríklad:

http://192.168.1.50:8080

Na Samsung Galaxy S24 Ultra otvor túto adresu v Chrome. Telefón aj Rokid Glasses musia byť na rovnakej Wi‑Fi alebo hotspot-e. V prehliadači sa zobrazí živý náhľad a tlačidlo na uloženie fotografie.

Poznámka: či YodaOS sprístupní hlavnú kameru sideloadovanej aplikácii cez Camera2, overí až reálny test na okuliaroch.
